Minha Evolução no Desenvolvimento Front-end

Este projeto faz parte da minha jornada de aprendizado em HTML5 e CSS3. Ao longo do desenvolvimento venho praticando:

  • HTML semântico;
  • Responsividade com Flexbox;
  • Tipografia fluida com clamp();
  • Organização de layouts;
  • Estruturação visual moderna;
  • Acessibilidade básica;
  • Revisar meu código;
  • Entender boas práticas;
  • Aprender conceitos modernos;
  • Identificar melhorias no layout e responsividade;
  • Efeitos visuais e animações;

Meu objetivo é continuar evoluindo gradualmente no desenvolvimento front-end, fortalecendo meus fundamentos antes de avançar para JavaScript, APIs e frameworks modernos.
